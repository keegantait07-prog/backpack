# Decisions

What was decided and why, so nobody re-argues it. Newest at the bottom.

## D-001 | 2026-11-22
Decision: Backpack has a six-role crew: lead, builder, design-reviewer, a11y-perf-reviewer, security-reviewer, verifier. Roles communicate only through files in `docs/crew/`.
Why: the owner wants a small, clear crew that hands work over in writing and improves through written lessons.
Approved by: owner.

## D-002 | 2026-11-22
Decision: the project is a git repository.
Why: the app is one 1.2 MB file with no history, so every change needs to be reversible.
Approved by: owner.
