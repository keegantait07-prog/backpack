# Tools

Every tool the crew keeps, with one line on why. Add a tool only when a real finding cannot be handled by the existing crew. If a tool goes a full cycle unused, propose removing it.

The project has no hooks, MCP servers or plugins of its own. The global Claude setup is not changed.

| Tool | Used by | Why it stays |
|---|---|---|
| `superpowers:writing-plans` | lead | Turns a goal into small ordered tasks. |
| `superpowers:verification-before-completion` | lead, verifier | Stops "done" being said without evidence. |
| `caveman:surgical-patch` | builder | Keeps edits small and bounded. |
| `design-skills:design-critique` | design-reviewer | Structured hierarchy and clutter review. |
| `design-skills:ux-writing` | design-reviewer | Checks interface wording. |
| `design-skills:accessibility-audit` | a11y-perf-reviewer | WCAG 2.2 audit of a built page. |
| `ecc:security-review` | security-reviewer | Escaping, scripts and privacy checklist. |
| Built-in browser tools | verifier | Screenshots, console errors and the restore test. |
